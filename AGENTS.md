# AutoLACP project instructions

- All source code, comments, logs, configuration, documentation, release notes,
  and publishing content must be written exclusively in English.
- AutoLACP is authoritative over native manual LACP configuration.
- Prefer current native Data Center topology, LACP, save/load, and co-op APIs.
- Do not add a periodic topology scan, custom save format, or custom network
  protocol.
- Do not publish or upload a release without explicit user approval.
