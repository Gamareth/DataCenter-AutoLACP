# AutoLACP 1.0.0

AutoLACP automatically manages Data Center's native LACP groups after cable
connections are registered.

## Highlights

- Create a native LACP group from two parallel physical routes.
- Extend that group when more parallel routes are connected.
- Resolve direct, patch-panel, chained patch-panel, and SFP routes.
- Keep native save/load and cable-removal behavior authoritative.
- Replace manual LACP actions with automatic-status controls.
- Process cable bursts with bounded per-frame work and no recurring scan.
- Receive verified-payload Steam Workshop updates after the initial manual
  installation.

Custom VLAN restrictions and co-op are not officially supported in this
release.
